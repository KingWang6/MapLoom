# Nanjing boundary provenance

The 11 district features were obtained from the publicly accessible Alibaba Cloud DataV GeoAtlas boundary endpoint for Nanjing (`adcode 320100`):

<https://geo.datav.aliyun.com/areas_v3/bound/320100_full.json>

The source coordinates were converted from GCJ-02 to WGS84 (EPSG:4326) by the project preprocessing workflow so that the boundary and OpenStreetMap POIs use the same coordinate reference system. The included features retain district names and administrative codes for 玄武区、秦淮区、建邺区、鼓楼区、浦口区、栖霞区、雨花台区、江宁区、六合区、溧水区、高淳区.

Public accessibility does not imply that the boundary is covered by the repository's software license. Users redistributing or refreshing it should review the source provider's current terms.
